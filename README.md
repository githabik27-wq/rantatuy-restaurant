# Рантатуй — сайт ресторана

Многостраничный сайт ресторана «Рантатуй» (Екатеринбург, Уралмаш, ул. Уралмашовских, 34).
Русская и английская версии, адаптив 360–1920px, без сборки и внешних зависимостей.

## Страницы

| Файл | Что |
|---|---|
| `index.html` | главная: hero, о ресторане, превью меню, сценарии, «Причины вернуться» (3 фото), бронь-баннер |
| `menu.html` | меню: завтраки, супы, горячее, десерты, напитки (с ценами) |
| `about.html` | о ресторане: подход, галерея зала, как найти |
| `promos.html` | акции и мероприятие: день рождения, будни с 9:00, «Рантатуй-суббота» |
| `booking.html` | бронь (форма) + контакты + доставка |

## Запуск

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## Структура

```
index.html about.html menu.html promos.html booking.html
css/styles.css      — токены дизайн-системы + адаптив
js/main.js          — RU/EN переключение, липкая мобильная панель, форма брони
assets/fonts/       — Onest (variable), PT Serif 700 (+italic), woff2, cyrillic+latin
assets/img/         — фото webp + jpg (fallback)
```

## Дизайн

- **Архетип:** тёплая тактильность — домашняя кухня, семейный зал, Уралмаш.
- **Палитра:** молоко `#F6F1E7`, кофе `#3B2A20`, терракота `#B4552E`.
- **Шрифты:** PT Serif (заголовки) + Onest (текст), кириллица, локально.
- **Приёмы:** зерно, ручной «scribble» в hero, меню с пунктирными лидерами,
  единая тёплая цветокоррекция фото, редакционные номера секций, одна primary-кнопка на экран.

## ⚠️ Черновой контент (подтвердить владельцу)

- **Меню и цены** — пример, придуман под концепцию «домашняя кухня»; позиции и цены нужно заменить реальными.
- **Акции** («День рождения», «Будни с 9:00», «Рантатуй-суббота») — черновые, условия и даты согласовать.
- **Доставка**: зона, минимальный заказ и время не указаны — уточнить у владельца.
- **Контакты** `@telegram`/`@vk`/телефон взяты из брифа как есть.
- Реквизиты компании и текст «Политики конфиденциальности» не добавлены.
