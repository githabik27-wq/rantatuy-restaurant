# Рантатуй — сайт ресторана

Одностраничный сайт ресторана «Рантатуй» (Екатеринбург, Уралмаш, ул. Уралмашовских, 34).
Русская и английская версии, адаптив 360–1920px, без сборки и внешних зависимостей.

## Запуск

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

Любой статический хостинг тоже подойдёт — это просто `index.html` + `css/` + `js/` + `assets/`.

## Структура

```
index.html          — разметка (RU по умолчанию)
css/styles.css      — токены дизайн-системы + адаптив
js/main.js          — переключение RU/EN, липкая мобильная панель, форма брони
assets/fonts/       — Onest (variable), PT Serif 700 (+italic), woff2, cyrillic+latin
assets/img/         — фото webp + jpg (fallback)
```

## Дизайн

- **Архетип:** тёплая тактильность (домашняя кухня, семейный зал, Уралмаш).
- **Палитра:** молоко `#F6F1E7`, кофе `#3B2A20`, терракота `#B4552E` (акцент ≤10% площади).
- **Шрифты:** PT Serif (заголовки) + Onest (текст), оба с кириллицей.
- **Приёмы:** зерно 2–5%, ручной «scrabble»-подчёркив в hero, меню-борд с пунктиром,
  единая тёплая цветокоррекция всех фото, одна primary-кнопка на экран.

## Плейсхолдеры `[НУЖНО: …]` (заполнить от владельца)

1. Кухня/концепция и абзац о шефе и продуктах (секция «О заведении»).
2. Меню: 3–6 фирменных позиций с ценами.
3. Условия доставки (зона, минимальный заказ, время).
4. Пара предложений о зале (свет, мебель, вид из окна).
5. Реквизиты компании и текст «Политики конфиденциальности».

Акции и мероприятие («День рождения», «Будни с 9:00», «Рантатуй-суббота») — черновые,
придуманы по запросу; цифры и условия нужно согласовать с владельцем.

## Форма брони

Фронтенд-валидация + сообщение об успехе. Отправку можно подключить к Telegram-боту
или почтовому бэкенду — сейчас заявка просто собирается на клиенте.
